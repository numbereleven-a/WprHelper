# WPR Helper

[English](README.md) · Русский

![Главное окно WPR Helper](docs/images/WprHelper-main.png)

WPR Helper — портативная программа для целевого сбора трасс Windows Performance Recorder. Она может запустить WPR непосредственно перед выбранной программой или записывать активность системы без запуска программы, а затем вовремя остановить сбор и сохранить готовый к анализу файл `.etl`.

Вместо ручного запуска команд и программы весь цикл сбора выполняется из одного окна:

```text
wpr -start CPU -filemode
<запуск выбранной программы>
wpr -stop Application.etl -skipPdbGen
```

## Зачем использовать

- трассировка начинается до запуска целевой программы, поэтому не теряются первые события;
- можно записывать активность системы без запуска конкретной программы;
- можно одновременно выбрать несколько встроенных профилей, например `CPU`, `DiskIO`, `FileIO`, `Registry` и `Network`;
- вместе со встроенными профилями поддерживаются пользовательские `.wprp`;
- запись останавливается вручную, после завершения программы, с задержкой или по ограничению времени;
- ETL можно сохранить в локальную или сетевую UNC-папку и при необходимости сделать вторую копию;
- основной ETL сразу записывается в выбранную папку, поэтому после сбора не требуется ненадёжное копирование из временной сессии;
- в окне видна точная команда `wpr.exe`, применяемая для текущего сбора;
- по умолчанию отключена генерация NGEN/PDB для ускорения завершения, но её можно включить отдельной опцией для подробных стеков управляемого кода;

## Требования

- Windows 10 или Windows 11 x64;
- `wpr.exe` из состава Windows или Windows Performance Toolkit;
- подтверждение прав администратора при запуске рабочего процесса записи.

Релизная сборка автономна и не требует отдельной установки .NET. Сам WPR в комплект не входит.

## Быстрый старт

1. Запустите `WprHelper.exe`.
2. Выберите целевую программу и при необходимости задайте аргументы либо снимите флажок **Запустить программу вместе со сбором** для системной трассировки.
3. На вкладке **Профиль WPR** отметьте один или несколько профилей. Для начала подойдёт `CPU` с режимом `-filemode`.
4. Выберите папку для ETL.
5. Нажмите **Начать сбор** и подтвердите повышение прав.
6. Закройте целевую программу, дождитесь заданного ограничения времени или нажмите **Остановить**.

После остановки WPR может некоторое время объединять буферы. WPR Helper дожидается завершения `wpr -stop`, показывает итоговый путь и включает кнопку **Открыть папку ETL**.

По умолчанию команда остановки получает ключ `-skipPdbGen`. События ETL сохраняются, а дополнительная папка `capture.etl.NGENPDB` не создаётся, но стеки .NET в WPA могут быть менее подробными. Снимите флажок **Не генерировать NGEN/PDB-символы**, если нужны символы управляемого кода.

## Профили WPR

Встроенные профили можно объединить в одном сборе. Например, для `CPU`, `DiskIO` и `FileIO` будет сформирована команда:

```text
wpr -start CPU -start DiskIO -start FileIO -filemode
```

Пользовательские профили задаются в поддерживаемом WPR формате `путь!имя_профиля`. Для известных профилей интерфейс показывает краткое описание, а ниже — полную командную строку, которая будет выполнена.
